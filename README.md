# Emberloop

Emberloop is a first-person time-loop puzzle game created for the Game Development Competition.

## Themes

### Time
The world resets at fixed intervals. The player's actions are recorded during each loop.

### Shadow
Each completed loop creates an echo of the player's previous actions. These echoes replay their recorded paths and are used to solve puzzles.

### Fire
Fire can persist through temporal resets and is used to empower or enable interactions that shadows cannot perform alone.

The three themes are interconnected through the game's core puzzle mechanics.

## Gameplay

Players explore an ancient dungeon trapped in a repeating temporal cycle.

Each loop records the player's movement. Previous versions of the player then replay those actions as echoes, allowing multiple actions to occur simultaneously.

Later puzzles introduce persistent fire mechanics and require coordinating multiple echoes across several loops.

## Controls

- WASD - Move
- Mouse - Look
- R - Rewind / Reset Loop
